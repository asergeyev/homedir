# backup-manifest.txt — what bin/homedir-backup copies and bin/homedir-restore puts back.
# Paths are relative to $HOME and kept at the same place under <backup>/home/; a trailing / marks a directory.
#   <group> <path>      copy it; groups: secrets work config claude apps vault projects personal (restore order)
#   <group> mcp:<glob>  Claude Code MCP servers whose names match (the first matching line wins). They hold passwords,
#                       so the backup saves them to <backup>/extra/ and the restore merges them into ~/.claude.json
#   - <path>            skip this path inside a listed directory (rsync pattern)
#   * <pattern>         skip this name at any depth (rsync pattern)
# Every group is backed up and restored like the others (personal is just big); the backup's --omit-work and
# --omit-personal leave one out, --omit-work with its MCP servers. secrets and work are restored owner-only (go-rwx).
# The tool configs homedir copies in (conf/configs.txt) are listed too: the restore puts yours back over homedir's
# copy, and bin/homedir-sync then compares them.
