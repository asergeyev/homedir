- **Try mise's dotfile tracking for the zsh and git configs.** With `mode = "track"`, your live files stay the source, as homedir wants, and mise records each edit in a local git history (`~/.local/state/mise/history/repo.git`) you can roll back. The backup keeps only the latest copy. Next: after the reinstall, track `~/.zshrc`, `~/.zprofile` and `~/.config/git/config` in `[dotfiles]` of `~/.config/mise/config.toml` (tracking is read only from the global config), and add `config .local/state/mise/history/` to `conf/backup-manifest.txt` so the history survives the next reinstall. The feature arrived in mise 2026.9.2 and still changes often, so check https://mise.jdx.dev/dotfiles/managed.html first.
